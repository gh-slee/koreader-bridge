# KM-P0-029: Rebuild the native app from current main and verify bundled workflows

## Goal

The last native build predates 1.1.0-dev.9. Build a fresh local app from current main so the owner can run acceptance (KM-P0-030) against the code that is actually merged, and record which commit it came from.

## Context

- docs/MACOS.md
- docs/DEVELOPMENT.md
- scripts/build_macos_app.py
- scripts/verify_macos_app.py

## Acceptance criteria

- [ ] `python3 scripts/build_macos_app.py` succeeds from a clean checkout of current main and reports the built app path.
- [ ] The build inputs match the main commit (no uncommitted or untracked sources bundled).
- [ ] `python3 scripts/verify_macos_app.py <app>` passes in a logged-in macOS session, or the ticket records that this step was handed to the owner.
- [ ] The built commit, build result and verify result are recorded in this ticket's Handoff (no local paths).

## Plan

- [ ] Claim on a macOS host and fetch origin/main.
- [ ] Run the build script; keep output under the ignored `.local/` folder.
- [ ] Run the verify script in a GUI session, or hand that step to the owner with the exact command.
- [ ] Record results and set the ticket to done.
